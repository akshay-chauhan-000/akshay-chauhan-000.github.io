Interactive simulations that run entirely in your browser. Each one is a small,
dependency-free implementation of a model I find worth playing with — the point
is to expose the parameters and let you push the system around, rather than to
show a finished figure.

Source for all of them lives under `static/sims/` in the
[site repository](https://github.com/akshay-chauhan-000/akshay-chauhan-000.github.io).
